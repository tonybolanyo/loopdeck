# Scripts para Mobius

En Mobius, los scripts son archivos de texto plano con extensión `.mos`.
Para automatizar el flujo, necesitamos crear e instalar scripts que se ejecuten
automáticamente cuando cambie el estado de la pista.

## Cómo instalar el script en Mobius:

1. Guardar el archivo `feedback.mos` en una carpeta del PC.
2. En Mobius, ir a **Configuration** => **Scripts**.
3. Hacer clic en **Add** y seleccionar el archivo `.mos`.
4. Reiniciar Mobius. Al arrancar, el comando `!autoload` del script
   hará que el script corra en segundo plano de forma invisible.
